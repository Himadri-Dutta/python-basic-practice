# 🐍 Python Basics – 30 Question Assignment

Solutions to 30 beginner Python problems covering functions, loops, conditionals, strings, and patterns.

## Sections

| Section | Questions | Topics |
|---------|-----------|--------|
| **A – Numbers** | 1–10 | Even/odd, largest, sum, factorial, digits, reverse, prime |
| **B – Strings** | 11–20 | Counting chars/vowels/words, reverse, palindrome, case conversion |
| **C – String + Loops** | 21–28 | Case counts, first/last char, indexing, longest word, vowel frequency |
| **D – Patterns** | 29–30 | Star and number patterns with nested loops |

## Run

```bash
python solutions.py
```

Requires Python 3.x. No external libraries needed.

## Notes

- Each question is a separate function with the name given in the assignment.
- Restrictions are followed (e.g. no `max()`, `len()`, `count()`, `split()`, `replace()`, or recursion where banned).
- Questions with multiple approaches (15, 20, 23) have separate `_loop` / `_slicing` / `_builtin` versions.
- Question 4 is named `find_largest3` to avoid clashing with Q3's `find_largest`.
